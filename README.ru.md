# Layout Indicator (`layout-indicator@tsv-tech`)

[English](README.md) | **Русский**

**Layout Indicator** — расширение GNOME Shell, которое показывает активную раскладку клавиатуры по краям экрана. Ещё оно может сообщать о каждой смене раскладки внешним программам: через файл или через команду, которую вы задаёте сами.

Расширение реагирует на сигнал `current-source-changed` и ничего не опрашивает в цикле. Оно работает с несколькими мониторами и хранит отдельный цветовой профиль для каждой раскладки.

---

## Возможности

### 1. Три независимых визуальных индикатора

Каждый индикатор включается и выключается в настройках отдельно. Все они обновляются сразу при смене раскладки.

* **Рамка по краям экрана (включена по умолчанию)**
  * Рисует цветную рамку на **всех подключённых мониторах**. Клики проходят сквозь неё (`reactive: false`).
  * Пересоздаётся сама, когда мониторы подключаются или отключаются, а также при смене разрешения или масштаба (`monitors-changed`).
  * **Стороны:** все четыре (**All Sides**) или любое сочетание **Top**, **Bottom**, **Left** и **Right**.
  * **Толщина:** `1`–`15 px` (по умолчанию `3 px`).

* **Линия под верхней панелью (необязательно)**
  * Рисует цветную линию по нижнему краю верхней панели через `box-shadow: inset`. Высота панели не меняется, иконки не сдвигаются.
  * Собственный inline-стиль панели сохраняется и возвращается, когда расширение отключают.
  * **Толщина:** `1`–`10 px` (по умолчанию `2 px`).

* **Системный акцентный цвет (необязательно)**
  * Меняет акцентный цвет GNOME (`org.gnome.desktop.interface` → `accent-color`) под активную раскладку.
  * Поддерживает все 9 акцентных цветов GNOME: Blue, Teal, Green, Yellow, Orange, Red, Pink, Purple и Slate.
  * Когда расширение отключают, ваш исходный акцентный цвет возвращается.

---

### 2. Цветовые профили для каждой раскладки

* **В списке только установленные раскладки.** Окно настроек читает `org.gnome.desktop.input-sources` и показывает по одной карточке на каждый источник ввода. Если установлен необязательный typelib `GnomeDesktop` 4.0, в карточке видно и полное название раскладки (например, `US — English (US)`).
* **Цвета RGBA.** У каждой раскладки есть свои палитры с прозрачностью для рамки и для линии под панелью, а также свой выпадающий список акцентного цвета.
* **Автоматическая палитра.** Новая раскладка получает следующий пресет из цикла из 8 пастельных цветов: Blue → Orange → Yellow → Teal → Purple → Green → Pink → Slate.
* **Сохраняется после удаления.** Профили хранятся в GSettings (`language-configs`) в виде JSON, ключ — ID раскладки. Если удалить раскладку и потом добавить её снова, её цвета вернутся.

**ID раскладки** — это ID источника ввода в верхнем регистре:

| Источник ввода                | ID              |
|-------------------------------|-----------------|
| `xkb` `us`                    | `US`            |
| `xkb` `ua`                    | `UA`            |
| `xkb` `de+nodeadkeys`         | `DE+NODEADKEYS` |
| `ibus` `mozc-jp`              | `MOZC-JP`       |

Варианты одной раскладки (например, `us` и `us+dvorak`) считаются разными раскладками, и цвета у них тоже отдельные.

### 3. Файл с раскладкой и пользовательская команда

* **Файл с раскладкой.** При каждой смене раскладки её ID (например, `US`) записывается в `$XDG_RUNTIME_DIR/layout-indicator`. Обычно это `/run/user/1000/layout-indicator`. Файл доступен только вашему пользователю и удаляется при выходе из сеанса. Прочитать его можно так:

  ```bash
  cat "$XDG_RUNTIME_DIR/layout-indicator"
  ```

* **Пользовательская команда (по умолчанию выключена).** При смене раскладки можно запускать любую команду. Она стартует асинхронно через `Gio.Subprocess`, а её вывод отбрасывается.
  * Командная строка делится на аргументы по правилам shell, но **сама команда запускается без shell**. Конвейеры (`|`), перенаправления (`>`) и `&&` не поддерживаются. Если они нужны, оберните команду в `sh -c '…'`.
  * **Подстановки.** Они заменяются внутри каждого аргумента, поэтому экранировать их не нужно:
    * `${layout}` — ID раскладки, например `US`.
    * `${body}` — JSON с данными, например `{"value":"US"}`.
  * **Пример (webhook / PhoneBox):**

    ```bash
    curl -s -X POST http://127.0.0.1:8765/api/push/my-value -H "Content-Type: application/json" -d ${body}
    ```

  * **Пример с shell:**

    ```bash
    sh -c 'echo ${layout} >> ~/layout-history.txt'
    ```

## Совместимость

* **GNOME Shell:** `47`, `48`, `49`, `50`. GNOME 46 не поддерживается, потому что в нём нет ключа `accent-color`.
* **Графический сервер:** Wayland. На GNOME 47–48 работает и X11.
* **Зависимости:** стандартные библиотеки GNOME Shell, GTK 4 и libadwaita. `GnomeDesktop` 4.0 необязателен и нужен только для полных названий раскладок. В Debian/Ubuntu он входит в пакет `gir1.2-gnomedesktop-4.0`.

## Структура проекта

```text
layout-indicator@tsv-tech/
├── extension.js              # Точка входа: enable()/disable(), реакция на смену раскладки
├── metadata.json             # Метаданные расширения
├── prefs.js                  # Точка входа окна настроек
├── lib/                      # Только для процесса GNOME Shell
│   ├── accentColor.js        # Подмена и восстановление акцентного цвета
│   ├── layoutExport.js       # Файл с раскладкой и пользовательская команда
│   ├── panelBar.js           # Линия под верхней панелью
│   └── screenBorders.js      # Рамки на каждом мониторе
├── prefs/                    # Только для процесса настроек
│   ├── commandGroup.js       # Группа «Layout Change Command»
│   ├── indicatorsGroup.js    # Группа «Visual Indicators»
│   ├── installedLayouts.js   # Список установленных источников ввода
│   └── languageGroup.js      # Карточки цветов для раскладок
├── shared/                   # Общий код для обоих процессов, без UI-импортов
│   └── languageStyles.js     # Палитра, чтение и запись language-configs
└── schemas/
    └── org.gnome.shell.extensions.layout-indicator.gschema.xml
```

## Установка

### Вариант А: из ZIP (рекомендуется)

Из папки с исходниками:

```bash
gnome-extensions pack --extra-source=lib --extra-source=prefs --extra-source=shared --force .
gnome-extensions install --force layout-indicator@tsv-tech.shell-extension.zip
```

`gnome-extensions pack` сам компилирует схему.

### Вариант Б: вручную

1. Создайте папку расширения. Её имя должно совпадать с `uuid` из `metadata.json`:

   ```bash
   mkdir -p ~/.local/share/gnome-shell/extensions/layout-indicator@tsv-tech
   ```

2. Скопируйте в неё всё из структуры проекта выше: `extension.js`, `prefs.js`, `metadata.json` и папки `lib/`, `prefs/`, `shared/` и `schemas/`.

3. Скомпилируйте схему:

   ```bash
   glib-compile-schemas ~/.local/share/gnome-shell/extensions/layout-indicator@tsv-tech/schemas/
   ```

### Затем

1. **Перезапустите GNOME Shell.**
   * Wayland: выйдите из сеанса и войдите снова.
   * X11 (GNOME 47–48): нажмите `Alt` + `F2`, введите `r` и нажмите `Enter`.

2. **Включите расширение:**

   ```bash
   gnome-extensions enable layout-indicator@tsv-tech
   ```

## Настройка

Откройте окно настроек:

```bash
gnome-extensions prefs layout-indicator@tsv-tech
```

Или нажмите кнопку настроек рядом с **Layout Indicator** в приложении «Расширения» или в Extension Manager.

### Сброс к настройкам по умолчанию

Эта команда сбрасывает все настройки и все сохранённые цветовые профили:

```bash
dconf reset -f /org/gnome/shell/extensions/layout-indicator/
```

## Переход с прошлых версий

* Файл с раскладкой переехал из `/tmp/layout` в `$XDG_RUNTIME_DIR/layout-indicator`. Обновите путь в скриптах и виджетах, которые его читают.
* Пользовательская команда теперь **по умолчанию выключена**, а её текст по умолчанию пустой. Если вы пользовались старой командой `curl …` по умолчанию, введите её снова и включите **Run Command on Layout Switch**.
* Старый шаблон с одинарными кавычками (`-d '${body}'`) по-прежнему работает.
* GNOME 46 больше не поддерживается.

## Решение проблем

* **Расширения нет в выводе `gnome-extensions list`.** Проверьте, что папка называется именно `~/.local/share/gnome-shell/extensions/layout-indicator@tsv-tech`. На Wayland ещё нужно выйти из сеанса и войти снова.
* **Окно настроек не открывается с ошибкой `schema_id`.** Скомпилируйте схему ещё раз (шаг 3 варианта Б) и проверьте, что в `metadata.json` есть `"settings-schema": "org.gnome.shell.extensions.layout-indicator"`.
* **Команда не запускается.** Для конвейеров и перенаправлений нужен `sh -c '…'`, а программа должна быть в `PATH`. Ошибки попадают в журнал.
* **Журнал:**

  ```bash
  journalctl -f -o cat /usr/bin/gnome-shell | grep -i "layout indicator"
  ```
